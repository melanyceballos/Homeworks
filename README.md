# Challenge 11 · Grafo de personas y ciudades

Instale dependencias con `npm install`, ejecute pruebas con `npm test` y levante la interfaz con `npm run dev`. El grafo mantiene nodos tipados y lista de adyacencia real; cada persona se conecta a su ciudad. Los colores distinguen tipos en `react-d3-graph`. El proyecto usa React 16.14 porque `react-d3-graph@2.6.0` declara React 16 como peer dependency.
