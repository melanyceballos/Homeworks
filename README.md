 Requisitos del Sistema

Para la ejecución local del proyecto se requiere tener instalado en el sistema:
* Node.js (Versión 18.0 o superior recomendada)
* npm 
* Un navegador web

Instrucciones de Instalación y Ejecución:

Sigue estos pasos para poner en marcha el proyecto en un entorno local:
Clonar o descargar el repositorio:
   git clone <https://github.com/melanyceballos/parcial-clinica>
   cd parcial-clinica

   Instalar las dependencias:
   npm install
   Iniciar el servidor de desarrollo:
   npm run dev

   Acceder a la aplicación:
Una vez iniciado el servidor, abre tu navegador e ingresa a la dirección mostrada en la terminal
